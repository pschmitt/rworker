Usage: __ME__ nix-cache NAME [--dry-run]

The cache part of `setup nix`: same as `__ME__ setup nix NAME --no-auth`.
See: __ME__ help setup

Lets an ad-hoc worker substitute from the private S3 Nix cache, using this
host's s3:// substituters, the trusted public keys and the AWS profile each
URL names (read-only). up and exec do it by default, together with the
access-tokens; --no-nix-cache keeps the worker free of the key.

  --dry-run   show the substituters, keys and profile names; push nothing
              (credentials are never printed)
