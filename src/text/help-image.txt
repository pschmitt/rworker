Usage: __ME__ image create [--flake FLAKE] [--upload [UPLOAD_OPTIONS]] [--json]
       __ME__ image upload --name NAME [UPLOAD_OPTIONS] IMAGE [--json]

Create builds the standalone rworker disk image by default. --flake selects
another flake, with optional #ATTR to select a specific image output.
Without --upload, create prints the image path in the Nix store.

Upload creates a private OpenStack image from a .raw, .img, or .qcow2 file.
Upload options:
  --name NAME        image name (required for upload, optional for create)
  --tag TAG          tag the uploaded image
  --cloud CLOUD      select a clouds.yaml entry (overrides OS_CLOUD)
  --project PROJECT  set the image's owner project by name or ID (requires permission)
