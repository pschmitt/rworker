Usage: __ME__ machines [-o json|wide | --wide] [--fresh | -w|--watch [-n SECONDS]]
          [-A|--all|--history] [--topic REGEX] [--agent REGEX] [--agent-id REGEX]

Aliases: ls, nodes, instances.

List ad-hoc workers and nixbot's pool workers,
with status, creating agent, topic, time to expiry and age.
EXPIRES "grace 42m": expired but in use, deleted after 1h without use.
Pool workers have no TTL; EXPIRES shows what the autoscaler last saw:
busy, idle 12m (drained after 20m idle with nothing pending) or draining.

  -o json        print the raw JSON instead of the table
  --wide, -o wide
                 add the owner, profile and IP addresses
  --topic REGEX, --agent REGEX, --agent-id REGEX
                 only workers whose topic, creating agent or agent id
                 matches (a leading ! inverts the match)
  -A, --all, --history
                 also include retired workers from history
  --fresh        wait for a fresh inventory snapshot
  -w, --watch    redraw the table in place every -n seconds (default 5),
                 marking rows: + new, ~ changed (status, IP, owner, expiry,
                 flavor), - gone. q quits, any other key refreshes now.
  -n SECONDS, --interval SECONDS
                 refresh interval for --watch
